# Vue 高手直達車 | vue-train-fast-track 🚀

這是線上課程 [Vue 高手直達車](https://www.pressplay.cc/project/751DA69033978D020540527674C35C83/about) 的程式庫！

本課程從零開始，系統化介紹 Vue 3，幫助你掌握現代前端開發所需的技能，並以實際範例與專案帶你快速進入 Vue 世界。

## ✨ 課程特色

- 使用 Composition API 與 `<script setup>` 標準寫法
- 範例與實戰兼具，幫助理解核心觀念
- 節奏流暢，深入淺出，適合想升級為 Vue 高手的你
- 涵蓋 Pinia、路由、元件封裝、佈署、與影片播放器整合等實用技能
